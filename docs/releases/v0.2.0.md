# QuantResearchAgent v0.2.0

This release turns the original seven-node quantitative-research MVP into a broader
research and advisory portfolio with explicit evidence, review, delivery, and
operational controls.

## Highlights

- Added listed-company research and corporate-advisory routes with approved Moutai
  and BYD showcase reports.
- Added public filing, PDF evidence, market-data, company-metric, and event-
  intelligence pipelines.
- Added Debate Gate, committee challenge, revision limits, and report update
  decisions for material events.
- Expanded deterministic analytics with fixed effects, transaction-cost-aware
  backtesting, DCF valuation, and sensitivity analysis.
- Added FastAPI research jobs, report downloads, event analysis, latency metrics,
  and structured failure diagnostics.
- Added a credential-free release benchmark and documentation consistency audit to
  GitHub Actions.

## Scope boundary

Industry research, market strategy, and statistical event study have platform route
and template contracts but do not yet have approved end-to-end executors. The API
job store and metrics registry are process-local; persistent queues, authentication,
and distributed monitoring remain production-roadmap items.

The project is a research-engineering prototype, not investment advice, automated
trading, audit assurance, or a regulatory opinion.
